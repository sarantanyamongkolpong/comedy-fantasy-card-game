## 1\. Hard Requirements — Core Battle (LOCKED)

- เป็น Turn-Based Card Battle: **Avatar เป็นตัวละครจริงบนสนาม**, Action Card เป็นคำสั่งให้ Avatar ทำงาน ไม่ใช่เอาการ์ด Avatar ไปทิ้งในกอง Action  
- ทีมละ **4 Avatars**; ชนะเมื่อกำจัดศัตรูทุกตัว; แพ้เมื่อ Avatar ฝั่งเราเสียชีวิตทั้งหมด  
- Factions: `Aegis Dominion` \= Tank, `Phantom Blades` \= DPS, `Celestial Nexus` \= Magic, `Sanctuary Order` \= Support  
- Stats หลัก Avatar: **ATK / DEF / SPD**; ให้ใช้ชื่อใหม่นี้ใน data/UI; ฟิลด์เก่า `POW`, `HP/MAG/RES/...` เป็น legacy ต้องทำ migration ที่ปลอดภัย ไม่ลบค่าเดิมก่อนย้าย  
- เทิร์นฝั่งที่ **Team SPD สูงกว่าเริ่มก่อน** แล้วสลับฝั่ง; สูตรรวม Team SPD และกรณีเสมอยัง PENDING ให้ห่อเป็น configuration/decision ไม่ล็อกตัวเลขมั่ว  
- **5 AP** ของฝ่ายผู้เล่นทุกต้นเทิร์นตัวเอง (reset); Action แต่ละใบมี AP Cost ระดับ **0–5** ตามข้อมูลการ์ด; หาก AP เหลือ 0 หรือเล่นไม่ได้ ผู้เล่นยังเลือก End Turn เอง ไม่ Auto End  
- **Action Deck 30 ใบ**, มือเริ่ม **5 ใบ**; การ์ดเหลือในมือคงไว้หลังจบเทิร์น; ต้นเทิร์นตนเองให้จั่วกลับขึ้นถึง 5 ใบ (หากมีการ์ดเพียงพอ); Effect เพิ่มจั่วระหว่างเทิร์นอนุญาตให้เกิน 5 ชั่วคราว; เมื่อจบรอบให้เลือกทิ้งฟรีจนเหลือไม่เกิน 5  
- **ทิ้งการ์ดจากมือเองในเทิร์นตัวเองเสีย 1 AP/ใบ** แยกจาก mandatory discard ที่ฟรี  
- เมื่อการ์ดใช้แล้วปกติลง **Discard Pile**; เมื่อ Draw หมดให้ Shuffle Discard กลับเป็น Draw โดยไม่รวม The Void  
- **The Void กลับมาใช้จริง** เป็นปลายทางของบางเอฟเฟกต์ (ไม่ใช่ Discard); แสดงกอง Draw/Discard/Void, ดูรายการใน Discard และ Void ได้ทุกเวลา; Card Effect เฉพาะใบอาจดึงคืนจากสองกองนี้ตามปลายทางที่ระบุ  
- การ์ด Action มีหมวดหลัก `ATK`, `DEF`, `Skill`; Action ประเภท Skill เป็น **ตัวสั่งเปิดใช้ Active ของ Avatar**, ไม่ได้กด Active ฟรีเอง; 1 Action Card ปกติสั่ง 1 Avatar Skill เว้นมีการ์ดระบุข้อยกเว้น  
- Generic Action ใช้ได้กับ Avatar ทุกฝ่าย; **FAC Action** จะใช้ได้ต่อเมื่อมี Avatar Faction ตรงกันอยู่ในทีม (เว้นแต่ Effect ของการ์ดระบุข้อยกเว้นอย่างชัดเจน); **ห้ามล็อกทั้ง Deck ให้ใช้ได้ Faction เดียว**  
- Data effect จะต้องรองรับ duration, turn tick, targeted/self/team, status, buff/debuff, passive trigger, stack policy, and removal. ถ้าความหมายการนับ 2 Turns ยัง PENDING ให้ระบุ assumptions ใน changelog \+ tests และแยก config เพื่อแก้ได้

## 2\. Avatar, Rank และ Gacha (LOCKED vs OPEN)

- Avatar rarity มี **N / R / Epic / EX** ไม่ใช่ Common/Rare/Epic/Legendary/Mythic; Action rarity มี **N / R / Epic / EX / FAC** (`EX` และ `FAC` เป็น top-tier เท่ากัน)  
- Avatar rarity abilities: N เน้น base stats บางตัวมี Active เล็กน้อย; R มี Active **หรือ** Passive; Epic มี Active **และ** Passive; EX มีครบพร้อม Ultimate. Trigger Active ยังต้องมี Action Card ที่เหมาะสม  
- EXP Lv สูงสุด **5** ตามสเปกล่าสุดที่คุย; Stars / Rank Promotion เป็นระบบคนละส่วน; ยังไม่ยืนยันเพดานดาวต่อ Rarity หรือสูตรใช้สำเนา ห้ามแอบล็อกเป็น N2/R3/Epic4/EX5  
- Upgrade/Enhance/Equipment, Hero Synthesis (เพิ่มดาว), Promotion Stones (เลื่อน Rank) วางโครง Data/API ให้ทำต่อได้, balance และต้นทุนที่ยังไม่ล็อกให้ `PENDING`  
- แยก **Avatar / Action / Companion Gacha**; Avatar กับ Action ใช้เงินสกุลเดียวกัน `G`; แกนเกมให้เปิดกาชาได้บ่อย  
- Gacha pity ที่คุยล่าสุด: Avatar/Action Epic guarantee ภายใน **100 pulls**; Avatar/Action top tier EX/FAC ภายใน **200 pulls**; Companion Epic guarantee **100 pulls**, ไม่มี top-tier pity. ต้องตรวจว่า Banner-specific counter และการ reset on hit ต้องตั้งค่าตามข้อมูลได้; rate, price, overlap-rule ยัง PENDING ไม่ใส่เลขสมมติใน production  
- Duplicate, ownership, locked/favorite/in-deck material protection ต้องมีแนวทางกันข้อมูลสูญหาย และ test; สัดส่วนการแปลงสำเนายัง PENDING

## 4\. Home, Gacha, Main Map, Economy และ UX

- The Hideout tiers: `Cabin → Bungalow → Cottage → Loft → Villa → Penthouse`. การอัปเกรดบ้านเปลี่ยน **รูปแบบบ้านให้เป็น Tier ล่าสุดเสมอ**; ไม่เพิ่ม Storage Slots อัตโนมัติ

- ข้อมูลอ้างอิงเฟอร์นิเจอร์ตาม Tier: Bungalow \+1 Box (50), Cottage \+1 Box (50), Loft \+1 Tall Cabinet (100), Villa \+1 Display Counter (100), Penthouse \+1 Large Tall Cabinet (150). รายละเอียดว่าเป็นของแถมหรือเพียง Unlock-to-buy และ Cabin base capacity **PENDING** อย่าเติมเอง

## 6\. Required Test Matrix / Acceptance Gate

- 4 Avatars selection, Faction mapping, rarity skill-slot validation; mixed Faction Deck allowed
