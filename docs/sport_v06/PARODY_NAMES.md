# SPORT COMPLEX v0.6 — parody names for artwork

Artist sheet for original drawings. This file lists parody names only.

Draw original characters, crests, machines, and places. Do not draw a real person's face, hair, body, tattoo, number, or pose. Do not draw a real logo, kit, livery, helmet, sponsor, badge, or a traced stadium or circuit. Famous team colours are not a reference. Pick the food-comic colours in the visual column.

`ipReview` = YES means the parody name is still a close echo. Keep that drawing extra original so the picture does not tighten the resemblance. Real identities are not written in this file.

Original fictional opponents are included so each sport has a full match or grid. Car and motorcycle rows are combined rider-or-driver plus machine entries. Those two sports have no coach cards in this pack.
